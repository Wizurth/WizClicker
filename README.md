<h1 align="center">WizClicker</h1>

A lightweight Windows tool for automating **keyboard and mouse inputs**.
It can simulate key presses, mouse clicks, and other input actions through a simple interface.

## 📦 Export

After building the project, use `export-final.bat` to create a single export package containing `repack.exe` and the required DLL files.

```bat
export-final.bat
```
